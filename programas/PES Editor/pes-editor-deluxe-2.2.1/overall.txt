# Overall rating weights for PES Editor Deluxe.
#
# ---------------------------------------------------------------
# HOW A RATING IS BUILT
#
#   rating = offset + sum over abilities of  weight x ability
#
# which is
#
#   75.28 + 1.60 x sum of  weight x (his ability - group average)
#
# written flat. The offset carries the "minus the group average"
# part, which is why it is large and negative. So twenty points
# above average on something his group is judged on counts for far
# more than thirty above on something it is not.
